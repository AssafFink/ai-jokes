# Milestones — תוכנית בנייה

> התוכנית לבניית האפליקציה, שלב אחר שלב. זהו קובץ חי: סמן משימות שהושלמו תוך כדי העבודה. Claude יעדכן אותו תוך כדי עבודתו.
>
> - **Milestone** = נקודת ציון גדולה שאפשר לעצור בה ולבדוק.
> - **Slice** = פיסת ערך שלמה אחת בתוך Milestone.
> - בונים Milestone אחד בכל פעם. בודקים שהוא עובד לפני הבא.

## כלל חשוב — אישור בין Milestones
אחרי סיום כל Milestone, Claude עוצר וממתין. אני (המפתח) בודק שה-Milestone עובד, ורק לאחר שאני מאשר במפורש — Claude ממשיך ל-Milestone הבא. אין להתחיל Milestone חדש לפני שאני מאשר.

התוכנית המפורטת לכל Milestone נכתבת לקובץ `spec/plans/milestone-N.md` (למשל `milestone-1.md`) לפני בנייתו.

## Milestone 1 — Walking Skeleton
> האפליקציה רצה מקצה לקצה כמעט בלי תוכן. זה מוכיח שהכל מחובר לפני שמוסיפים פיצ'רים.
- [x] הקמת monorepo: `client/` (Vite + React + TS) ו-`server/` (Express + TS)
- [x] Route `POST /api/joke` שמחזיר בדיחה קבועה (stub)
- [x] הלקוח מציג תיבת טקסט + כפתור, קורא ל-Route ומציג את התשובה
- [x] dev proxy: Vite מעביר `/api` לשרת
- **הערה:** אין מסד נתונים בפרויקט — שורת ה-"database" הכללית אינה רלוונטית.
- **מוכן כאשר:** הדף נפתח מקומית בדפדפן, לחיצה מציגה את בדיחת ה-stub ללא שגיאות. 🟢

## Milestone 2 — יצירת בדיחה אמיתית
> הבדיחה נוצרת בפועל ע"י ChatGPT לפי הנושא.
- [x] Slice 2.1: חיבור ה-Route ל-OpenAI (`gpt-4o-mini`) עם קריאת המפתח מ-`OPENAI_API_KEY`
- [x] Slice 2.2: פרומפט — נושא → בדיחה בשפת הנושא; ללא נושא → נושא רנדומלי בעברית
- [x] Slice 2.3: טיפול בשגיאות בסיסי (מפתח חסר / כשל קריאה)
- **מוכן כאשר:** לחיצה עם נושא ובלי נושא מחזירה בדיחה אמיתית מהמודל. 🟢
